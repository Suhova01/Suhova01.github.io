Как менять сайт

Всё делается мышкой, за пару минут. Сломать сайт нельзя — не бойтесь пробовать.

1 Откройте нужную страницу

Слева — разделы сайта, такие же, как в меню на сайте: 🏠 Главная, 📁 Портфолио, 🧸 Моя группа…

  1. Нажмите на раздел слева.
  2. Справа появятся страницы. У нужной нажмите Изменить ✏️
👩‍🏫 Своё фото, имя и почту меняйте в разделе «Обо мне».

2 Поменяйте текст

Слева — поля для текста, справа — как это будет выглядеть на сайте. Пишите прямо в поля, справа всё сразу меняется.

Страница состоит из блоков. У каждого блока есть заголовок и текст.

  1. Чтобы открыть блок — нажмите на его название.
  2. Новый блок — кнопка Добавить блок +
  3. Удалить блок — крестик ✕ справа от него.
  4. Поменять блоки местами — потяните за полоски ═ сверху блока.

3 Добавьте фото 📸

Фото добавляются внутрь блока. Откройте блок и найдите «🖼️ Фотографии».

  1. Нажмите Добавить фото +
  2. Нажмите Выберите изображение
  3. В окошке нажмите 📤 1. Загрузить с компьютера и выберите снимок.
  4. Нажмите ✅ 2. Вставить выбранное
  5. Если хотите — напишите подпись под фото.
💡 Хотите сразу много фото? Повторите шаги для каждого снимка. Уже загруженные фото лежат в окошке — их можно просто выбрать и вставить ещё раз.
📏 Большие фото с телефона (больше 3 МБ) сайт открывает медленно. Перед загрузкой их удобно уменьшить, например на сайте squoosh.app.

4 Ссылки, видео и файлы

🔗 Ссылка или видео
В блоке «Ссылки» → Добавить ссылку + → напишите название и вставьте адрес (начинается с https://). Видео сначала загрузите на YouTube, ВК или Яндекс.Диск.
📎 Файл (Word, PDF, презентация)
В блоке «Файлы для скачивания» → Добавить файл + → название → Выберите файл → загрузите → вставьте.

5 Опубликуйте ✅

Пока вы не опубликуете — изменения видите только вы.

  1. Нажмите зелёную кнопку Опубликовать вверху.
  2. Под ней нажмите Опубликовать сейчас
⏱️ Сайт обновится сам примерно через 1–2 минуты. Если не видно изменений — обновите страницу сайта.

? Если что-то пошло не так

Случайно что-то стёрла
Если ещё не опубликовали — нажмите стрелку ← слева вверху и согласитесь уйти без сохранения. Если потом спросят про «резервную копию» — нажмите «Отмена». Всё вернётся как было.
Красная надпись у поля
Это поле нужно заполнить (например, заголовок блока) или адрес ссылки написан с ошибкой.
Просит войти
Нажмите «Войти через GitHub» — это нормально, так бывает, например, на новом компьютере.
Ничего не помогает
Напишите тому, кто делал сайт: всё, что когда-либо публиковалось, можно вернуть.
